# Ambilight Screen

Простая утилита для двух мониторов: когда на основном экране включено видео или фильм, второй мягко подсвечивает комнату в тон происходящему.

Никаких силуэтов или резких деталей — просто плавный рассеянный свет. Весит 20 КБ, не грузит систему и тихо ждёт в трее.

---

## Как пользоваться

1. Запусти `Ambilight.exe`.
2. Нажми **`Ctrl + Shift + L`** — подсветка включится.
3. Нажми ещё раз (или `Esc`) — выключится.

### Управление:
* **Колёсико мыши** или **`↑` / `↓`** — яркость.
* **`B`** — режим (рассеянный градиент или один сплошной цвет на весь экран).
* **`←` / `→`** — скорость смены цвета (плавнее / быстрее).
* **`C`** — режим кино (обрезка чёрных полос сверху и снизу).
* **`S`** — поменять мониторы местами.
* **Правый клик** — меню настроек.

---

## Автозапуск

Правый клик по значку в трее → **«Запускать вместе с Windows»**.
